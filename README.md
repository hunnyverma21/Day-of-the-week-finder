# Day of the Week Finder

A beginner-friendly Python program that accepts a date and tells you which day of the week it falls on.

## Features

- Accepts date in `DD-MM-YYYY` format
- Uses Python's built-in `datetime` module
- Validates the entered date
- Handles invalid dates
- Displays the correct day of the week

## Technologies Used

- Python
- datetime module

## How to Run

1. Make sure Python is installed.
2. Open a terminal in this project folder.
3. Run:

```bash
python day_of_the_week_finder.py
```

## Example

```text
========================================
       DAY OF THE WEEK FINDER
========================================

Enter date (DD-MM-YYYY): 29-09-2026

----------------------------------------
Date: 29-09-2026
Day: Tuesday
----------------------------------------
```
